# Siqi Song · AI / Computer Vision Portfolio

A concise personal portfolio for AI and computer-vision roles, featuring research, SmartSeg productization, embodied VLA, 3D affordance reasoning, and selected professional experience.

## Local preview

Serve the `dist` directory with any static HTTP server, then open the local URL in a browser.

## GitHub Pages

The repository includes `.github/workflows/deploy-pages.yml`. It publishes the contents of `dist` whenever the `main` branch is pushed.

Before the first deployment, open the GitHub repository's **Settings → Pages** and set **Source** to **GitHub Actions**.
